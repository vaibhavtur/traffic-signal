# Traffic Signal Control — React + Vite

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite (usually http://localhost:5173).

## Build
Run `npm run build`. Use `npm run preview` to preview the production build locally.

Features kept from the supplied HTML: traffic light phases, live countdown, pause/start, skip, reset, custom stop duration, arrow direction switches, responsive layout.
